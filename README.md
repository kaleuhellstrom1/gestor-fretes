# Gestor de Fretes

Sistema web desenvolvido como atividade acadêmica da APO da disciplina Fundamentos de Programação para Internet.

## Objetivo

O sistema tem como objetivo auxiliar no gerenciamento de fretes, permitindo organizar produtos, endereços, transportadores e informações de transporte.

## Tecnologias utilizadas

- PHP
- HTML
- CSS
- JavaScript
- MySQL
- Bootstrap
- XAMPP

## Funcionalidades

- Cadastro de produtos.
- Cadastro de endereços de origem e destino.
- Cadastro de transportadores.
- Registro e consulta de fretes.
- Relatórios de fretes.

## Como executar o projeto

1. Instale o XAMPP.
2. Inicie o Apache e o MySQL.
3. Coloque a pasta do projeto em `htdocs`.
4. Acesse pelo navegador:

   http://localhost/gestor-fretes/
